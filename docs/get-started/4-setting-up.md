# Setting Up

Using Vitre is extremely quick and easy, that's why it was developed in the first place.

Simply put this snippet of code in a client runtime script such as a `LocalScript` or a `ModuleScript` getting required on the client.

```luau
-- Main.client.luau
const Vitre = require(path.to.vitre)

Vitre:setup()
```

And done! You can now get started on making your custom windows that fit your needs.
