# Introduction

Vitre is a reactive developer focused UI library. It is based on centau's work: Vide.

If you have experience with Vide, most of its concepts can carry over to Vitre.

---

The problems Vitre aims to solve are the following:
- Quick and easy to deploy to test features instead of relying on messy prints
- Make projects that already use Vide able to use it for dev tools
- Strictly typed and new solver friendly code

---

### Why the Name?

Since I am French, Vitre means glass pane in French.
