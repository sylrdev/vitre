# .Vide

A direct access to the Vide library used by Vitre. That access exists in case you need to use Vide for Vitre related logic while not using Vide on your project.

::: info
Vitre uses a forked version of Vide that provides more instance types as the latest Wally version is missing a lot of them.

If you wish to use that fork in your project, you can find it on Wally under [sylrdev/vide](https://wally.run/package/sylrdev/vide?version=0.4.1).
:::

See the full Vide documentation [here](https://centau.github.io/vide/).
